## 两个站分别展示了什么？

两个站都使用老猫云名称，展示内容却不相同。

这里把 `laomao.one` 称为第一个站，把 `laomaocloudvpn.com` 称为第二个站。域名是区分这两份页面记录的依据，品牌名称相同不能补齐它们之间的关系。

| 项目 | 第一个站 | 第二个站 |
| --- | --- | --- |
| 品牌与自称 | 首页、关于页介绍老猫云加速服务 | 下载页自称老猫云机场客户端 |
| 客户端平台 | 首页写全平台支持 | 下载页逐项列出平台及安装方式 |
| 退款与工单 | 退款有期限及用量前提，需提交工单 | 遇到问题可在账户后台提交工单 |
| 官网、备用及防失联说明 | 页面没有说明 | 页面没有说明 |
| 公告渠道 | 读不到 | 读不到 |
| 地址关系 | 没有出现第二个站的域名 | 没有出现第一个站的域名 |
| 开始或购买按钮 | 购买跳往其他域名，附推广参数 | 开始及下载跳往其他域名，附推广参数 |

## 平台和退款具体怎么写？

第一个站写了退款条件，第二个站列出了平台清单。

第一个站的套餐按月展示。首页把客户端支持写成覆盖全平台，这是该站自己的介绍。

它把退款期限写为 3 天，且有使用流量的上限条件。提交工单是页面给出的办理方式；只看期限，不能略去用量前提。

第二个站列出 Windows、macOS、iOS、Android、路由器及 Linux。iOS 对应 App Store，Android 列有 APK 或 Play Store。

该下载页还写到多台设备可同时使用，应用内有更新提示。第二个站的退款规则，以及两站的试用、到期规则，页面没有说明。

## 官网和公告依据齐全吗？

已读页面缺少能把站点身份与公告对应起来的依据。

页面使用品牌名称和介绍服务，与页面明确自称官网是不同的记录。已读内容不能列为站点自述官网，也没有公告点名可用于交叉对照。

两站互不提及，不能把其中一个当作另一个的备用入口。

## 按钮跳转该核对什么？

购买或开始按钮都会跳到其他域名，并带推广参数。

推广参数指链接中附带的推广信息；跳转后的域名未在这里展开。查看时，把打开页面的地址和点击后的地址分别记下，别把落地页面自动归给原站。

第一个站的购买入口，与第二个站的开始、下载入口，都要分别看跳转。客户端介绍、工单说明和按钮去向是不同项目，不能相互代替身份依据。
